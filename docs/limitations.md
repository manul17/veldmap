# Known Limitations

Explicit scope boundaries and current implementation limits of VeldMap. Entries are updated as slices close and capabilities land.

## Planetary Model & Platform (Committed v1 Scope)

- **Flat WGS84 ellipsoid (no 3D DEM mesh displacement in v1; nadir camera currently):** VeldMap v1 renders a smooth WGS84 ellipsoid (`height = 0.0`) with a nadir camera ([Design Decisions](decisions.md)). Terrain relief is delivered as quantitative GPU layers (hillshade, slope, aspect) in Slice 5B-1 rather than 3D vertex displacement, avoiding renderer-induced relief parallax and keeping uniform nadir GSD for orthophoto alignment, split-screen swipe, and temporal diffing. (Source-imagery relief distortion in non-orthorectified swaths is unaffected.)
- **Desktop native GPU backends only (Vulkan, DirectX 12, Metal):** VeldMap restricts `wgpu` to native primary desktop backends (`Backends::PRIMARY` minus `BROWSER_WEBGPU`), intentionally excluding OpenGL/GLES and browser WASM to keep Reverse-Z, `view_formats`, and `R32Float` behavior uniform across platforms. Systems without hardware Vulkan/DX12/Metal drivers require a software fallback such as Mesa Lavapipe or Microsoft WARP.

## Current Milestone Limits (Post-Slice 5B-2a)

- **Scientific `R32Float` GPU precision vs. native `f64` CPU readout:** GPU scientific and screen-space Band Math / temporal diff tracks upload numeric bands as IEEE-754 `R32Float` (24-bit mantissa, ~7 significant decimal digits), which quantizes 32-bit integer (`u32`/`i32`) and `f64` rasters above `2^24` during display rendering. For **local** datasets, zoom-invariant cursor readouts read native full-precision values in `f64` directly from the source base IFDs, preserving exact raw DN, `raw * scale + offset` physical values, computed Band Math indices, dual-epoch scalar deltas (`Δ = B − A`), and ESA `SCL` classes. For **remote HTTP Range COGs**, cursor hover stays strictly cache-only via `SharedChunkCache` (resolving once level-0 chunks have streamed into memory so mouse movement never triggers blocking HTTP requests): this is lossless for `u8`/`i8`/`u16`/`i16`/`f32` and categorical `R8Uint`/`R16Uint` COGs, while remote `u32`/`i32`/`f64` scientific COGs currently quantize to `R32Float` (`f32`) on hover.
- **Cloud COG streaming & STAC discovery limits (Slices 4A–5B-2a):** Remote HTTP streaming requires tiled Cloud-Optimized GeoTIFFs (COGs) with coarse overviews fitting `MemoryBudget`; remote stripped GeoTIFFs, PNGs, and JPEGs are rejected (`RemotePassUnsupported`) to prevent accidental whole-file HTTP downloads. STAC `/search` supports `sortby` and bounded `links[rel="next"]` (`GET`/`POST` + `merge`) pagination up to `500` cumulative items. Persisted remote COG URLs strip query strings, presigned tokens, and userinfo for secret hygiene; on restore `401`/`403`, single-attempt origin-fenced `stac_item_href` refresh re-signs expired assets whose canonical URL matches the persisted asset (imported `.veldmap.json` items always refresh anonymously without attaching private credentials; bare direct COG URLs without a `stac_item_href` still require re-opening after presigned token expiry).
- **Upcoming analytics, terrain, and mission-codec tracks (`v1.0`–`v1.1`):** Raster support currently covers local and cloud GeoTIFF/BigTIFF/COG (`Display`, `Scientific`, `Categorical`, multi-asset GPU Band Math + `SCL` masking, and multi-temporal `Timeline` scrubbing with dual-epoch GPU scalar diffing & 0%-bleed-through RGB cross-fade), local world-file PNG/JPEG overlays, split-screen swipe, sanitized `.veldmap.json` / `session.json` workspaces, and cartographic PNG export. Multi-polygon AOI zonal stats & 1D time-series (`Slice 5B-2b`), analytical UX & Float32 GeoTIFF export (`Slice 5B-2c`), quantitative terrain relief (`Slice 5B-1a`/`5B-1b`), and v1.1 cloud-native EOPF Zarr / CDSE S3 (`4B-1`), local Sentinel-2 `.SAFE` JP2 (`3C-1`), NetCDF-4 (`6`), and optional 1:1 2D orthographic inspector (`3B-2`) remain upcoming (see [plan.md](../plan.md)).
- **JPEG EXIF orientation:** Georeferenced JPEGs are decoded in stored pixel orientation without applying EXIF `Orientation` rotation/flips (world files and photogrammetry outputs reference raw stored pixel coordinates).
- **CRS grid shifts, georeferencing & MGRS:** Grid-based datum shifts (NADCON5/NTv2/OSTN15) are not bundled, so datasets on tectonic or grid-shifted datums may retain decimetre-to-metre residual offsets relative to WGS84/ITRF (surfaced as UI warnings). Georeferencing covers affine projected/geographic rasters and regular rectangular tie lattices; scattered GCPs and Rational Polynomial Coefficients (RPCs, Tag `50844`) for unorthorectified imagery are outside v1 scope. Bidirectional MGRS parsing and formatting cover UTM bands `C`–`X` (including Norway and Svalbard exceptions); latitudes beyond `84°N` / `80°S` fall back to `"UPS N"` / `"UPS S"` display labels rather than UPS grid-zone coordinates.
- **UI fonts, PNG overlay font & Linux native dialogs:** Bundled DejaVu fallbacks cover Latin, Extended Cyrillic, Greek, Arabic, Hebrew, Armenian, Georgian, and GIS symbols in the desktop UI, but CJK and Indic scripts are not bundled. Exported cartographic PNGs capture the offscreen globe framebuffer (excluding `egui` chrome such as the Swipe divider handle) and composite optional overlays using a compact ASCII + common GIS-symbol bitmap font (non-ASCII caption characters are omitted). On minimal Linux window managers without `xdg-desktop-portal` or `zenity`, native file dialogs are unavailable—use drag-and-drop, the Layers panel `Path…` prompt, or CLI path arguments instead.
- **Credentials & analytical persistence:** Per-layer band/track, stretch, colormap, palette, sanitized remote COG, heterogeneous `BandMath` recipes, multi-temporal `Timeline` state, split-screen swipe layouts, and vector `outline_only` flags persist in `session.json` and portable `.veldmap.json` project files. Custom XYZ API keys, named Custom STAC profiles/credentials (`Bearer`, `ApiKey`, `SasQuery`), and GPU tile VRAM cap (`128–4096 MiB`) persist privately in `settings.json` (`0600` on Unix); imported `.veldmap.json` remote URLs only receive private credentials when they match a configured profile's endpoint origin in `settings.json`. CDSE S3 credentials (`ProjectDirs/.env`) land in Slice `4B-1`; GPU backend/logging overrides remain controlled via environment variables (`RUST_LOG`, `WGPU_BACKEND`, `WGPU_POWER_PREF`).
