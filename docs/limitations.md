# Known Limitations

Explicit scope boundaries and current implementation limits of VeldMap. Entries are updated as slices close and capabilities land.

## Planetary Model & Platform (Committed v1 Scope)

- **Flat WGS84 ellipsoid (no 3D DEM mesh displacement in v1; nadir camera currently):** VeldMap v1 renders a smooth WGS84 ellipsoid (`height = 0.0`) with a nadir camera ([Design Decisions](decisions.md)). Terrain relief is delivered as quantitative GPU layers (hillshade, slope, aspect) in Slice 5B-1 rather than 3D vertex displacement, avoiding renderer-induced relief parallax and keeping uniform nadir GSD for orthophoto alignment, split-screen swipe, and temporal diffing. (Source-imagery relief distortion in non-orthorectified swaths is unaffected.)
- **Desktop native GPU backends only (Vulkan, DirectX 12, Metal):** VeldMap restricts `wgpu` to native primary desktop backends (`Backends::PRIMARY` minus `BROWSER_WEBGPU`), intentionally excluding OpenGL/GLES and browser WASM to keep Reverse-Z, `view_formats`, and `R32Float` behavior uniform across platforms. Systems without hardware Vulkan/DX12/Metal drivers require a software fallback such as Mesa Lavapipe or Microsoft WARP.

## Current Milestone Limits (Post-Slice 3A-1)

- **Planetary basemaps & local GeoTIFF/BigTIFF/COG draping; drone RGB codecs & cloud COGs upcoming:** VeldMap currently supports offline/live HTTP basemaps (NASA GIBS, EOX Sentinel-2 Cloudless, Custom XYZ/TMS) and local chunky (`PlanarConfiguration = 1`) 8/16-bit and `f32` non-YCbCr/non-Palette GeoTIFF/BigTIFF/ZSTD-COG overlays with a basic Layer List (visibility, opacity, zoom-to-extent, reload, remove) and base-resolution RGB cursor readouts. `YCbCr`/`WebP` TIFFs, local PNG/JPEG + world-file/`.prj` overlays, native OS file dialogs, layer reordering, expanded CRS, geodesic measurement, and GeoJSON overlays land in Slice 3A-2; scientific `R32Float`/`R8Uint`/`R16Uint` tracks (`Planar = 2`, `Palette`, 4-band RGBN) land in Slice 3B; STAC/COG HTTP Range streaming lands in Slice 4A (see [plan.md](../plan.md)).
- **Navigation & viewport controls:** Interactive controls currently cover primary-button drag orbit, scroll/pinch zoom-at-cursor, Go-To DD/DMS/MGRS, live/offline/ellipsoid basemap switching & settings, graticule toggle, and `N`/compass Reset-North. Manual heading rotation, keyboard pan/zoom, and multi-viewport split panes are not yet implemented.
- **CRS, datum shifts, georeferencing & MGRS coverage:** `veldmap-core::geo::projection` currently supports WGS84 UTM (`326xx`/`327xx`), Gauss-Krüger on Pulkovo 1942 (`284xx`), MSK-61 (`6336101..=6336103`), and Web Mercator (`3857`) using static 7-parameter Helmert datum shifts (horizontal only; no grid-based shifts such as NADCON5/NTv2/OSTN15 or WKT1/WKT2 `.prj` parsing yet—datasets on tectonic/grid-shifted datums may retain decimetre-to-metre offsets relative to WGS84/ITRF). Expanded pure-Rust CRS/WKT coverage (`proj4rs`/`proj4wkt`/`crs-definitions` evaluation), explicit Helmert rotation conventions, linear units (feet), user-defined TM parameters, and world files land in Slice 3A-2. Georeferencing covers affine projected/geographic rasters and regular rectangular tie lattices; scattered GCPs and Rational Polynomial Coefficients (RPCs, Tag `50844`) for unorthorectified imagery are outside v1 scope. MGRS parsing covers UTM bands `C`–`X` (including Norway `31V`/`32V` and Svalbard `31X`/`33X`/`35X`/`37X` bounds), excluding UPS polar zones (`A`, `B`, `Y`, `Z`).
- **Default UI fonts only:** Only `eframe`'s built-in default fonts are loaded until Slice 3A-2 adds a permissively licensed fallback font, currently limiting glyph coverage for non-Latin scripts in file paths or metadata.
- **Basemap settings persisted; sessions & CDSE credentials upcoming:** Basemap selection, NASA GIBS date, Custom XYZ/TMS config, graticule toggle, and disk cache budget persist durably to `settings.json` via `write_json_durable_private()` (`0600` on Unix). Minimal local session / recent-files persistence lands in Slice 3A-2, CDSE credentials (`ProjectDirs/.env`) land in Slice 4B, and full multi-layer analytical workspace sessions land in Slice 5A; GPU/logging overrides remain controlled via environment variables (`RUST_LOG`, `WGPU_BACKEND`, `WGPU_POWER_PREF`).
