# Known Limitations

Explicit scope boundaries and current implementation limits of VeldMap. Entries are updated as slices close and capabilities land.

## Planetary Model & Platform (Committed v1 Scope)

- **Flat WGS84 ellipsoid (no 3D DEM mesh displacement in v1; nadir camera currently):** VeldMap v1 renders a smooth WGS84 ellipsoid (`height = 0.0`) with a nadir camera ([Design Decisions](decisions.md)). Terrain relief is delivered as quantitative GPU layers (hillshade, slope, aspect) in Slice 5B-1 rather than 3D vertex displacement, avoiding renderer-induced relief parallax and keeping uniform nadir GSD for orthophoto alignment, split-screen swipe, and temporal diffing. (Source-imagery relief distortion in non-orthorectified swaths is unaffected.)
- **Desktop native GPU backends only (Vulkan, DirectX 12, Metal):** VeldMap restricts `wgpu` to native primary desktop backends (`Backends::PRIMARY` minus `BROWSER_WEBGPU`), intentionally excluding OpenGL/GLES and browser WASM to keep Reverse-Z, `view_formats`, and `R32Float` behavior uniform across platforms. Systems without hardware Vulkan/DX12/Metal drivers require a software fallback such as Mesa Lavapipe or Microsoft WARP.

## Current Milestone Limits (Post-Slice 5A-1 / Milestone v0.5 In Progress)

- **Scientific `R32Float` GPU precision vs. native `f64` CPU readout:** GPU scientific and screen-space Band Math tracks upload numeric bands as IEEE-754 `R32Float` (24-bit mantissa, ~7 significant decimal digits), which quantizes 32-bit integer (`u32`/`i32`) and `f64` rasters above `2^24` during display rendering. For **local** datasets, zoom-invariant cursor readouts read native full-precision values in `f64` directly from the source base IFDs, preserving exact raw DN, `raw * scale + offset` physical values, computed Band Math indices, and ESA `SCL` classes. For **remote HTTP Range COGs**, cursor hover stays strictly cache-only via `SharedChunkCache` (resolving once level-0 chunks have streamed into memory so mouse movement never triggers blocking HTTP requests): this is lossless for `u8`/`i8`/`u16`/`i16`/`f32` and categorical `R8Uint`/`R16Uint` COGs, while remote `u32`/`i32`/`f64` scientific COGs currently quantize to `R32Float` (`f32`) on hover.
- **Cloud COG streaming & STAC discovery limits (Slices 4A & 5A-1):** Remote HTTP streaming requires tiled Cloud-Optimized GeoTIFFs (COGs) with coarse overviews fitting `MemoryBudget`; remote stripped GeoTIFFs, PNGs, and JPEGs are rejected (`RemotePassUnsupported`) to prevent accidental whole-file HTTP downloads. STAC `/search` currently returns a single page (up to `100` items; `next`-link pagination and `sortby` land in Slice `5B-2a`), and remote COG / `BandMath` layers are excluded from `session.json` persistence until sanitized cloud workspace persistence lands in Slice `5A-2`.
- **Upcoming swipe, terrain, temporal, and mission-codec tracks (`v0.5`–`v1.1`):** Raster support currently covers local and cloud GeoTIFF/BigTIFF/COG (`Display`, `Scientific`, `Categorical`, and multi-asset GPU Band Math + `SCL` masking) plus local world-file PNG/JPEG overlays. Split-screen swipe, sanitized cloud/Band-Math workspace persistence & cartographic PNG export (`Slice 5A-2`), quantitative terrain relief (`Slice 5B-1`), multi-temporal timeline diffing (`Slice 5B-2a`), AOI zonal stats & Float32 GeoTIFF export (`Slice 5B-2b`), and v1.1 cloud-native EOPF Zarr / CDSE S3 (`4B-1`), local Sentinel-2 `.SAFE` JP2 (`3C-1`), NetCDF-4 (`6`), and optional 1:1 2D orthographic inspector (`3B-2`) remain upcoming (see [plan.md](../plan.md)).
- **JPEG EXIF orientation:** Georeferenced JPEGs are decoded in stored pixel orientation without applying EXIF `Orientation` rotation/flips (world files and photogrammetry outputs reference raw stored pixel coordinates).
- **CRS grid shifts, georeferencing & MGRS:** Grid-based datum shifts (NADCON5/NTv2/OSTN15) are not bundled, so datasets on tectonic or grid-shifted datums may retain decimetre-to-metre residual offsets relative to WGS84/ITRF (surfaced as UI warnings). Georeferencing covers affine projected/geographic rasters and regular rectangular tie lattices; scattered GCPs and Rational Polynomial Coefficients (RPCs, Tag `50844`) for unorthorectified imagery are outside v1 scope. MGRS parsing covers UTM bands `C`–`X` (including Norway and Svalbard exceptions) and excludes UPS polar zones (`A`, `B`, `Y`, `Z`).
- **UI fonts & Linux native dialogs:** Bundled DejaVu fallbacks cover Latin, Extended Cyrillic, Greek, Arabic, Hebrew, Armenian, Georgian, and GIS symbols, but CJK and Indic scripts are not bundled. On minimal Linux window managers without `xdg-desktop-portal` or `zenity`, native file dialogs are unavailable—use drag-and-drop, the Layers panel `Path…` prompt, or CLI path arguments instead.
- **Credentials & analytical persistence:** Per-layer band/track, stretch, colormap, and palette selections persist in `session.json`; Custom XYZ API keys, Custom STAC endpoints/credentials (`Bearer`, `ApiKey`, `SasQuery`), and GPU tile VRAM cap (`128–4096 MiB`) persist privately in `settings.json` (`0600` on Unix). Sanitized remote COG layers, band-math recipes, and split-pane/swipe layouts extend `session.json` and `.veldmap.json` in Slice `5A-2`; CDSE S3 credentials (`ProjectDirs/.env`) land in Slice `4B-1`; GPU backend/logging overrides remain controlled via environment variables (`RUST_LOG`, `WGPU_BACKEND`, `WGPU_POWER_PREF`).
